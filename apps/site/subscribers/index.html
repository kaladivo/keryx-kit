Company news. Signed, or not shown.

A company invited you to follow its announcements in Keryx. No email address, no phone number, no account.

Install the app How to join

01 Install

Get the app.

Any device

Web app

Open it in your browser and add it to your home screen. On an iPhone, use Safari. There is no App Store app yet.

v1b3coder.github.io/keryx

Open the web app

Android

Android app via Obtainium

  1. Install Obtainium.
  2. Add an app with this source: https://github.com/v1b3coder/keryx
  3. Obtainium installs Keryx and keeps it updated.
Check the signing certificate

Every release is signed with the same key. Tools such as AppVerifier can check this SHA-256 fingerprint before the first install:

5E:5A:CD:AF:31:88:49:F9:6D:C4:F5:08:A0:DA:A5:A4:74:BC:60:B2:3A:2C:63:9D:33:75:85:FF:F5:E7:C8:A1

On phones without Google services, the app uses ntfy for notifications and asks you to install it the first time you join a company.

Install Keryx only from these links. The checks happen inside the app, so a fake app could show you anything.

04 Limits

What Keryx can't protect you from.

The moment you join
Confirm a look-alike address, or join while an attacker controls the company's website, and you subscribe to the attacker.
The publishing service
The company may publish through a hosted service. It cannot sign messages, but an attacker there could hold messages back, or ship altered software to capture a staff member's signing key.
If a company's keys stop checking out
The app stops showing its messages, warns you and offers to remove it. It never asks you to scan a new code.
Your own phone
Anyone with your unlocked phone, or malware on it, can read stored messages.
Connection data
Like any website, the company's servers see your IP address when the app checks for news. There is no name or account to tie it to.

This page is the same for every company. It never shows a company name, so nobody can use it to pose as one.
