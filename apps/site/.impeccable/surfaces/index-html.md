## Direction contract

THESIS: A Swiss identity-program page that proves instead of claims: the real app screen, the
real signed file and a live signature check carry the argument. Refuses the dark-shield security
template and the cream-serif editorial page.

OWN-WORLD: White paper, near-black ink, one committed saturated blue (the Keryx app's own
primary) as full-bleed fields for the opening and the close. Red only for rejected or look-alike
states. Atkinson Hyperlegible Next as the grotesk, flush-left on a 12-column grid; Atkinson
Hyperlegible Mono only for real data (domains, paths, JSON, fingerprints). Hairline rules, square
corners, no icons, no badges, no eyebrows, no cards.

Trezor, three files and a QR; we can withhold but not forge, and here is the caveat; request a
pilot.
